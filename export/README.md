# export — Allowlist-Export (R8)

Platzhalter. Der Exporter erzeugt aus einer Instanz einen **veröffentlichbaren**
Datensatz per **Allowlist** (E26): freigegeben werden ausschliesslich

```
name · area · ring · summary · citation · first_seen
```

Nie exportiert werden `rationale`, `relevance_org`, `draft_arguments`,
`reviewer` und Events. Was neu ins Schema kommt, ist standardmässig privat.

Kommt in **R8** — frühestens, wenn das Schema zwei Zyklen überlebt hat.
